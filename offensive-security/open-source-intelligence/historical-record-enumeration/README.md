# OSINT Investigation Using Historical Academic Records

## Overview

This project focused on solving an Open Source Intelligence (OSINT) challenge through publicly available information sources. The objective was to locate a historical telephone number used for class registration at the University of Maryland University College (UMUC) in 1999 through internet-based research methods.

The investigation required identifying relevant archival sources, conducting targeted searches, analyzing historical documents, and validating findings through challenge completion.

## Challenge Objective

The challenge required locating the telephone number used for UMUC class registration through the Interactive Registration Information System (IRIS) during 1999.

The answer was not directly provided and required investigative research using publicly available sources. CMIT_321_CTFPresentation.pdf 【1-36a4ca】

## Investigation Methodology

### Problem Analysis

The initial challenge provided a specific objective:

> Determine the phone number used for UMUC class registration through the IRIS touch-tone registration system during 1999.

Based on the timeframe involved, academic catalogs were identified as a likely source of historical registration information. CMIT_321_CTFPresentation.pdf 【1-36a4ca】

### Information Discovery

Search engine queries were used to locate archived university catalogs from the relevant time period.

Research techniques included:

- Targeted keyword searches
- Historical document discovery
- Source validation
- Archive identification

The investigation led to a publicly accessible PDF version of the 1998–1999 UMUC Undergraduate Catalog. CMIT_321_CTFPresentation.pdf 【1-36a4ca】

### Document Analysis

After locating the historical catalog, document search functionality was used to identify references to the IRIS registration system.

The key search term:

```text
IRIS
```

enabled rapid navigation to the relevant registration information contained within the catalog. CMIT_321_CTFPresentation.pdf 【1-36a4ca】

### Validation

The discovered information was submitted to the challenge platform.

Successful flag generation confirmed that the research findings were accurate and complete. CMIT_321_CTFPresentation.pdf 【1-36a4ca】
