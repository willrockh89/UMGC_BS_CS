1. Established foundational understanding of network architecture, OSI/TCP-IP models, and hardware infrastructure.
2. Built and documented network segmentation, IP addressing schemes (IPAM), and MAC address tracking for system accountability.

### Phase 2: System Hardening & Security Engineering
1. Implemented access control policies, system hardening configurations, and baseline security standards across Windows and Linux environments.
2. Applied script automation via PowerShell and Bash to streamline administrative auditing and policy enforcement.

### Phase 3: Threat Modeling & Defensive Operations (Blue Team)
1. Modeled attack vectors using the OWASP framework to identify potential vulnerabilities in application and network topologies.
2. Formulated Incident Response plans, risk assessments, and compliance mapping aligned with NIST cybersecurity guidelines.

### Phase 4: Portfolio Integration & Synthesis
1. Consolidated technical deliverables, reports, and code artifacts into version-controlled repositories.
2. Standardized documentation across all academic projects to adhere to high-precision engineering standards.

Transitioning military precision and operational discipline from aerospace propulsion and technical operations into cybersecurity requires an unrelenting adherence to function over form. In complex enterprise networks—much like flight-critical systems—a single overlooked configuration or unmapped endpoint can compromise structural integrity. This repository represents the methodical execution of cybersecurity fundamentals: building low-maintenance, resilient, and verifiable security architecture from the ground up. Every lab, script, and documentation file within this program was executed with strict attention to detail, ensuring that academic concepts directly support real-world, mission-critical defensive operations.
